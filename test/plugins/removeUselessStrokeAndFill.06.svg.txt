Don't remove stroke attributes when the stroke is set in the style
attribute with an uppercase property name. CSS property names are
case-insensitive, so STROKE:red must keep stroke-width from being treated
as useless.

===

<svg xmlns="http://www.w3.org/2000/svg">
    <g style="STROKE:red">
        <path d="M0 0h10" stroke-width="4"/>
        <path d="M0 5h10" stroke-width="4"/>
    </g>
</svg>

@@@

<svg xmlns="http://www.w3.org/2000/svg">
    <g style="STROKE:red">
        <path d="M0 0h10" stroke-width="4"/>
        <path d="M0 5h10" stroke-width="4"/>
    </g>
</svg>
